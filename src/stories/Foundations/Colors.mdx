# Colors

OhmSavvy's palette is built around a "precision electronics workbench" idea rather than any
single product category — it needs to feel equally at home on a multimeter review, a soldering
iron comparison, or an oscilloscope guide. Copper/amber reads as stripped wire and solder; green
reads as an oscilloscope trace or a continuity-test LED; the neutral base is a warm off-white /
charcoal rather than pure white or black, like an enclosure or bench material.

Toggle the **Theme** control in the toolbar above to compare light and dark.

## Usage

| Token | Role |
| --- | --- |
| `--background` / `--surface` / `--surface-raised` | Page ground and card grounds, in ascending elevation |
| `--foreground` / `--muted` | Primary text, secondary/caption text |
| `--border` | Hairlines, card borders, table rules |
| `--accent` / `--accent-foreground` | Primary CTA, category labels, "reasons to avoid" markers |
| `--signal` / `--signal-bg` | "Top pick" / "best overall" callouts, "reasons to buy" markers |
| `--warn-bg` | Reserved for caution/warning callouts (not yet used in a component) |

**Rule of thumb:** accent = brand/action, signal = "this is the verified good outcome." Don't use
signal for anything that isn't an endorsement — it's the one color on the page that means
"we checked this and it's the one to buy."
