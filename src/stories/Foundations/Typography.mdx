# Typography

Two typefaces, each with one job.

- **IBM Plex Mono** (`--font-display`) — headings, labels, badges, prices, anything that should
  read like it came off a multimeter's digital display. Used with slightly tightened tracking
  (`-0.01em`).
- **Source Sans 3** (`--font-sans`) — body copy, verdicts, FAQ answers. Chosen for long-form
  legibility; this is what a reader spends the most time in.

## Rules

- Running text stays near 65 characters wide (`max-w-2xl` on prose blocks).
- Headings get `text-wrap: balance` so they don't orphan a single word on the last line.
- Never mix the two faces inside one sentence — a label can sit next to body copy, but a single
  string is always one face or the other.
